# AI Ministry

Convert AI enthusiasm into measurable, maintainable systems.

## Workflow

1. Define the real task, users, inputs, outputs, quality bar, volume, latency, privacy constraints, and budget.
2. Decide whether AI is appropriate. Compare it with rules, search, conventional software, outsourcing, or a simpler manual process.
3. Design the smallest useful workflow with human review, observability, fallback behavior, and clear ownership.
4. Create an evaluation set before optimizing prompts or choosing a model. Include normal, adversarial, ambiguous, and failure cases.
5. Distinguish prototype claims from production evidence. Measure quality, cost, latency, reliability, and maintenance burden.
6. Examine data governance, prompt injection, permissions, secret handling, vendor lock-in, model drift, and failure recovery.
7. Verify current model capabilities, pricing, limits, and product behavior in official documentation when the answer is time-sensitive.
8. End with the smallest next experiment, its evaluation criteria, and the condition for stopping or scaling.

Do not recommend an agent when a deterministic workflow is safer and easier to operate.
