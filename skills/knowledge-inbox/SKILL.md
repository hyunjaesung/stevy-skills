# Knowledge Inbox

Transform incoming material into source-grounded, connected notes rather than an isolated summary pile.

## Workflow

1. Identify the source, author, publication date, capture date, canonical URL or file, and content type.
2. Obtain the best available text. Prefer an official transcript or source document; disclose when only partial text or secondary coverage is available.
3. Separate source claims, supporting evidence, uncertainty, the user's observations, and AI interpretation.
4. Write a source note with a concise summary, key claims, useful examples, questions, actionable implications, and citation details.
5. Extract only durable concepts that deserve separate evergreen notes. Name each note as a claim or idea rather than a vague topic.
6. Connect notes to existing concepts, projects, decisions, and areas using meaningful links.
7. Record a decision or task only when the material actually changed an intended action.
8. If the user supplies a vault path, follow its existing conventions before creating folders or templates. Otherwise return portable Markdown and ask where it should live only when persistence is required.

Do not fabricate transcript passages, metadata, or citations. Avoid storing secrets or sensitive personal data without explicit permission.
